# Phase 8: Frontend Figma — All Domains

## Status: In Progress

## Objective

Design all frontend screens in Figma before any code is written. Every authoring form, list page, character wizard step, and character sheet view gets a Figma frame before implementation begins in Phase 9.

## Deliverable

This phase is Figma only. Do not write or modify any frontend code here.

## Prerequisite

## Rule

8.1 (Effect Editor Flow) is designed first — it is the shared reference all domain subplans depend on.
All domain subplans (8.3 onward) are written after Phase 8.3 (Spell) is approved. Spell establishes the baseline pattern every other domain plan follows.
