Use case: ui-mockup

Asset type: high-fidelity desktop web application settings concept, 16:9 landscape

Design direction: A dark Forge settings rail remains visible while the right pane routes between separate Profile, Preferences, and Account pages. The rail contains the Settings title, description, signed-in email, and section navigation without an avatar. The content pane uses dense form rows, strong dividers, restrained forge-orange actions, teal focus states, and red only for destructive actions.

Constraints: no gradients, glassmorphism, parchment, fantasy illustration, billing, notifications settings, public profile, avatar, dice controls, sound controls, particle controls, or dashboard card grid.
