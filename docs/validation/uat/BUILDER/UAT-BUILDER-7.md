# UAT-BUILDER-7: Build the Characters P2 and P3 will use in The Campaign

Build the Characters P2 and P3 will use in The Campaign.

Level 1 (Single-user basics) · Feature BUILDER · Mode: Group (P1, P2, P3) · Path position 36 of 191

## Prerequisites

- The account **P1** exists (watches only).
- The account **P2** exists.
- The account **P3** exists.

## Accounts and windows

- **Roles used:** P1, P2, P3
- **Windows:** Each role is a different person in their own browser, signed in to their own account.

## Steps

Mark each step: `[P]` passed, `[F]` failed, `[-]` not reached. Leave `[ ]` until run.

1. [ ] **P2:** Open `<STAGING_URL>/characters` and choose **Create Character**. Name it "Bryn", choose any Race, the Fighter Class and any Background, take the default ability method and equipment, and save the draft.
2. [ ] **P2:** Go to the **Review** step, fix anything listed under **Needs attention**, and choose **Activate**.
3. [ ] **P3:** Repeat steps 1 and 2 for a Fighter named "Cade".
4. [ ] **P2 and P3:** Open **Characters** and check the new Character is listed once.

## Expected

- Each Character (Bryn for P2, Cade for P3) commits, opens a Sheet with the chosen Class and hit points at maximum, and is listed once.
- Neither Character is in any Campaign yet (the Campaign scenarios assign them).

## Other users see

- **P1:** Nothing of these Characters in their own Characters list: private Characters are not visible to other players.
