# EXPLORATORY-3: Set up a new encounter on an uploaded map as GM

Take a map image and set up an Encounter on it, ready for players to join.

Level 0 (Orientation and exploratory tasks) · Feature EXPLORATORY · Mode: Solo (GM) with a facilitator playing P2 · Path position 4 of 190

Do not open the scripted scenario files before your Result is written: they name every button and would hide the confusion this task exists to find. This task is not pass/fail.

## Prerequisites

- The review data provides the account GM, who owns the four review Campaigns.
- The review data provides the account P2 as a second member to take a seat in a new Campaign.
- Use the provided file [assets/sample-battle-map.png](../assets/sample-battle-map.png): The 1000 x 750 map with a 50-pixel grid. You may use any image of your own instead.

## Roles and windows

- **Roles used:** GM, P2
- **Tester role:** GM. You use one account from your set, in your normal browser, and you never act as another role.
- **Facilitator:** the owner, signed in as P2 in a separate browser profile, following the script below. The facilitator does only what the script says, when the trigger happens, and does not explain controls.

## Facilitator script

1. Before the tester starts: P2 signs in in a separate profile and waits on the Campaigns page. P2 does nothing unprompted.
2. When the tester says they have invited P2: P2 accepts the invitation and assigns a Character of their choice if asked.
3. When the tester says the Encounter is started: P2 opens the Campaign, reports exactly what the board shows (map, own token, other tokens) and whether anything is visible that looks like it should be hidden.

## Task

- **Goal:** Take a map image and set up an Encounter on it, ready for players to join.
- **Scope:** Create a throwaway Campaign "UAT Explore Map", invite P2, add the map, place the players' Characters and at least two creatures, and start the Encounter. End when P2 reports the board.
- **Look for:** map scale and grid setup, token placement, how you decided between a Scene and an Encounter, and anything the players could see that you meant to keep hidden.

Follow [how to run a task](README.md#how-to-run-a-task) and write the Result below when you stop. Tell the facilitator in words when a trigger in the script happens (for example "my Character is ready").

## Afterwards

- GM: archive "UAT Explore Map" and remove P2's membership from it.
