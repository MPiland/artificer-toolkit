## Current decision

Artificer Toolkit is MVP-ready for the defined D&D 5e 2014 scope. No open P0/P1 defects remain. The complete SRD corpus, copied-aggregate identity isolation, authored-field parity, shared authoring workspace, design-token conformance, Builder-to-Sheet lifecycle, Sheet command persistence, responsive authoring behavior, and authenticated desktop/mobile runtime journeys are green. Campaign transfers and grants, VTT combat, additional game systems, and other post-MVP work remain explicitly out of scope.
