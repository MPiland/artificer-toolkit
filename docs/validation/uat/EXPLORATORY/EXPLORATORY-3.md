# EXPLORATORY-3: Set up a new encounter on an uploaded map as GM

Take a map image and set up an Encounter on it, ready for players to join.

## Prerequisites

- The review data provides the accounts GM and P2.
- Use the provided file [assets/sample-battle-map.png](../assets/sample-battle-map.png): The 1000 x 750 map with a 50-pixel grid. You may use any image of your own instead..

## Accounts and windows

- **Accounts:** GM (`Review_Gm_Rowan`), with P2 (`Review_Pl_Bryn`) in a second profile
- **Windows:** One browser profile per account ([how](../README.md#running-several-users-side-by-side)).

## What is ready for you

- Before you start (operator): **GM** creates a throwaway Campaign "UAT Explore Map", invites `Review_Pl_Bryn` by username, and **P2** accepts and assigns a Character (for example a copy of Pyra built in the Builder).

## Task

- **Goal:** Take a map image and set up an Encounter on it, ready for players to join.
- **Scope:** Add the map, place the players' Characters and at least two creatures, and start the Encounter. End when a player window shows the board and its own token.
- **Look for:** map scale and grid setup, token placement, how you decided between a Scene and an Encounter, and anything the players could see that you meant to keep hidden.
