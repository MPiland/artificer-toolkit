# EXPLORATORY-3: Set up a new encounter on an uploaded map as GM

Take a map image and set up an Encounter on it, ready for players to join.

Level 3 (Core play) · Feature EXPLORATORY · Mode: Group (P4 is the tester, P5 follows the script) · Path position 85 of 195

Do not open the scripted scenario files before your Result is written: they name every button and would hide the confusion this task exists to find. This task is not pass/fail.

## Prerequisites

- The account **P4** exists and hosts no Campaign yet (a free account allows one active hosted Campaign and GM already hosts The Campaign, so P4 is the tester and hosts the new one). P4 needs no Character.
- The account **P5** exists and is a member of P3's Campaign only (see [SOCIAL-2](../SOCIAL/UAT-SOCIAL-2.md)); P5 takes a player seat in the new Campaign.
- Use the provided file [assets/sample-battle-map.png](../assets/sample-battle-map.png): The 1000 x 750 map with a 50-pixel grid. You may use any image of your own instead.

## Accounts and windows

- **Roles used:** P4, P5
- **Windows:** Each role is a different person in their own browser, signed in to their own account.
- **Tester:** P4, who becomes the host of the new Campaign, in their own browser. You never act as another role.
- **P5:** a second person, in their own browser and signed in to their own P5 account, following the script below. They do only what the script says, when the trigger happens, and do not explain controls.

## Script for the second person

1. Before the tester starts: P5 waits on the Campaigns page. P5 does nothing unprompted.
2. When the tester says they have invited P5: P5 accepts the invitation and assigns a Character of their choice if asked.
3. When the tester says the Encounter is started: P5 opens the Campaign, reports exactly what the board shows (map, own token, other tokens) and whether anything is visible that looks like it should be hidden.

## Task

- **Goal:** Take a map image and set up an Encounter on it, ready for players to join.
- **Scope:** Create the Campaign "P4's Campaign" (P4 hosts it), invite P5, add the map, place a token for P5's Character (P5 builds one if asked) and at least two creatures, and start the Encounter. End when P5 reports the board.
- **Look for:** map scale and grid setup, token placement, how you decided between a Scene and an Encounter, and anything the players could see that you meant to keep hidden.

Follow [how to run a task](README.md#how-to-run-a-task) and write the Result below when you stop. Tell the second person in words when a trigger in the script happens (for example "my Character is ready").

## Afterwards

- P4: leave P4's Campaign active with P5 seated and the map in place; [ROOM-10](../ROOM/UAT-ROOM-10.md) uses it next and archives it. P5 deletes any Character built for this task.
