# Slice SPELLS-33: creature trait, action and reaction closed rules

Living handoff for SPELLS-33 (creature traits, actions and reactions closed rules become core authoring options).

## Current task

SPELLS-33.T1: classify the creature closed-rule kinds as description-only, existing options or new options (D156), reusing the SPELLS-4 T2 and SPELLS-31 T5 option groups where they fit, and propose a split into subtasks of size 1, 2, 3 or 5 for a ruling.

## T1 classification (D156)

Files are under `packages/source-data/src/srd/creatures/`. Class C deletes the kind and keeps the description, class A converts to existing options with a parity proof, and class B needs a new or extended generic option, ruled before code. "Task" is the proposed subtask below; ATTACK-11 marks the Multiattack kinds that ATTACK-11.2 owns.

Totals: **C 79, A 23, B 230** (B: 38 Multiattacks owned by ATTACK-11.2, 93 join a SPELLS-4.T2 group, 17 join a SPELLS-31 group, 82 need a creature-only new group).

### Vocabulary checked for the class B rulings

- `SAVING_THROW_MODIFIER` params are `{ability, conditionTypeId?, ruleDefinitionId?, requiresHolderSeesSource?}` (`packages/schema/src/grants/modifier.ts:61`). "Advantage on saves against being X" is class A through the Steel Will pattern (`hunter.ts:209-225`, one entry per ability with the condition). No "against spells" or "against magic" qualifier exists, so Magic Resistance, Gnome Cunning, Duergar Resilience and the sleep half of Fey Ancestry join SPELLS-4.T2j.
- Voluntary movement through hostile footprints is refused and ending a move in one is refused (`packages/rules-runtime/src/encounterMovementPassageContacts.ts:35`, `encounterMovementPassageBoundary.ts`), so Air Form, Water Form and Incorporeal Movement change resolved state and are class B (T6k1). No squeeze rule exists, so the 1-inch-gap halves (Amorphous and the form traits) stay description-only.
- Creature slots are authored as SPELL_GRANT entries with PREPARED, LIMITED_USE and CAST_AT_LEVEL plus `charges` {FIXED_AMOUNT, LONG_REST} (`acolyte.ts:57-80`, also Androsphinx and Spirit Naga). The `CREATURE_SPELLCASTING_SLOTS` rule beside them is redundant (C). Mage, Lich, Guardian Naga, Gynosphinx, Cult Fanatic, Druid, Priest and Mummy Lord lack the charges, which the same pattern expresses (A, T3b).
- ATTACK-11.2 states that all 142 SRD Multiattacks are authored as slot sets and that the stat-block audit refuses a description-only Multiattack. Every Multiattack kind (including the shared `CREATURE_MULTIATTACK` with 44 references) is therefore deleted by ATTACK-11.2, not by a SPELLS-33 subtask.
- ENEMY_NEAR_TARGET is a rider restriction (Sneak Attack, class A). Whether a standing ATTACK_ROLL advantage modifier accepts it was not confirmed, so Pack Tactics is in T6d3 and moves to A at the start of that task if it does.
- No disease condition, illumination predicate, terrain predicate, holder-death trigger or containment relationship exists. The ACTOR_RELATIONSHIP module already expresses Cloaker and Darkmantle attach (`cloaker.ts:329-380`), which T6a3 extends.

### Decision candidate D161: SYSTEM admission kind

A `RESOLVE_ACTION` may be raised by the rules rather than a player when it carries `systemTrigger: { parentCommandId }`. It is the only admission that lets a defeated actor be the source. Undo and void treat the parent and the system root as one change.
